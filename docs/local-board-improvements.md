# 로컬 게임판 UI·턴 흐름 개선

이 문서는 일차별 개발 일정과 별도로 진행한 로컬 게임판 개선을 기록한다. 적용 대상은 현재 `/game/demo`의 로컬 게임과 연습 화면이다. 온라인 방과 Firebase 게임 API에는 아직 연결되지 않았다.

## 화면과 카드

- 게임판을 딥 네이비·차콜 배경과 앤틱 골드 포인트로 정리하고, 흰색을 포함한 보석 색상과 광택을 구분하기 쉽게 조정했다. 은행·플레이어 보유량·구매 카드 보너스·귀족 조건에 같은 색 체계를 적용했다.
- 플레이어마다 구매 카드의 영구 할인과 실제 보유 보석을 나누어 표시한다. 모든 플레이어의 보유 보석을 볼 수 있으며 아이콘과 수량을 같은 기준으로 정렬했다.
- 개발 카드를 세로형 초상화 카드로 바꾸고 점수는 왼쪽 위, 할인 보석은 오른쪽 위, 필요한 보석은 왼쪽 아래에 배치했다. 5색 카드에 각각 6장씩 30장의 그림을 연결하고, 귀족 5장의 초상화도 추가했다.
- 단계 헤더를 1단계 초록·2단계 노랑·3단계 파랑으로 구분했다. 귀족·시장·은행의 제목 줄을 맞추고, 은행과 현재 플레이어 행동을 오른쪽 세로 열에 배치했다. 카드와 귀족의 조건을 게임판에서 바로 읽을 수 있도록 크기와 간격을 조정했다.
- 카드 구매 모달에 카드 원래 비용, 영구 할인, 보유량, 실제 사용량, 황금 대체량과 부족분을 나누어 보여준다. 상단의 예약 카드 버튼으로 보유 예약 카드를 열 수 있다. 상세 규칙은 상단의 `/rules` 탭으로 이동했다.

## 턴과 보상 연출

- 새 로컬 게임과 같은 인원 재시작은 게임판을 먼저 준비한 뒤 시작 안내 모달을 연다. 무작위로 정해진 첫 플레이어를 안내하고, **게임 시작하기**를 누른 시점부터 첫 턴의 3분을 센다.
- 로컬 게임 한 턴의 제한은 3분이며 30초가 남으면 한 번 알린다. 시간이 끝나면 엔진의 `TIMEOUT` 행동으로 필요한 초과 보석 반환이나 귀족 선택까지 처리하고 다음 플레이어의 턴을 시작한다. 시간 안에 행동을 마치면 보상 연출이 끝난 뒤 다음 플레이어로 자동 전환한다.
- 카드 구매 시 모달 전체가 카드 오른쪽 위 할인 보석으로 모이고, 보석이 구매자의 해당 영구 할인 칸으로 이동한다. 보석 획득과 카드 예약 시에는 은행 보석이 플레이어의 보유 칸으로 이동한다. 예약으로 황금을 받지 못하는 경우에는 황금 이동 효과도 나오지 않는다.
- 귀족 방문 시 귀족 카드가 초상화로 모이고, 초상화가 점수 칸으로 이동한다. 보유 보석·영구 할인·점수는 보상이 도착할 때 증가하도록 표시한다. 연출 중에는 행동한 플레이어의 테두리를 유지한다. 움직임 줄이기 설정에서는 이동 연출을 건너뛴다.

## 검증과 범위

- 엔진의 시간 초과 경로에서 정상 턴, 초과 보석 반환 중인 턴, 귀족 선택 중인 턴을 테스트했다. `npm run typecheck`, `npm test`(77개 통과), `npm run build`가 통과했다.
- 로컬 브라우저에서 보석 획득, 카드 구매, 귀족 선택, 두 예약 경로의 황금 이동과 턴 전환을 확인했다. 새 게임·같은 인원 재시작의 안내 모달에서 대기 중 03:00이 유지되고, 시작 버튼을 누른 뒤 카운트다운이 진행되는 것도 확인했다.
- 로컬 게임 상태는 브라우저 메모리에만 있으며 새로고침하면 연습 화면으로 돌아간다. 3분 제한과 `TIMEOUT` 처리는 현재 로컬 게임의 운영 규칙이다. 실제 온라인 게임의 시간 정책과 서버 검증은 별도로 구현해야 한다.
