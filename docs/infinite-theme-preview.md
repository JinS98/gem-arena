# 히든테마

멀티 대기실(방장)과 한 PC 게임 시작 창에서 네 번째 옵션 `히든테마`를 선택한다. 비밀번호 `0530` 확인에 성공해야 선택이 적용된다. 취소하거나 틀리면 기존 테마를 유지한다. 비밀번호는 선택 UI 잠금이며 서버 인증이나 보안 경계가 아니다. 헤더의 인피니트 테마 메뉴는 제거했고 이전 `/examples/infinite` 주소는 한 PC 게임으로 이동한다.

게임 시작을 누른 뒤 INFINITE 인트로가 표시되며 3.5초 후 게임판으로 자동 전환한다. 버튼이나 Escape로 건너뛸 수 있다. 한 PC 첫 턴의 3분은 인트로 종료 후 시작된다. 멀티는 서버에서 시작된 게임에 입장할 때 각 참가자에게 인트로를 표시하고 기존 서버 타이머를 사용한다.

`hidden`은 클라이언트 테마 목록, Firestore 방 테마 허용 목록, Functions 공개 방 목록 동기화에 등록된다. 실제 멀티/한 PC 게임 엔진을 그대로 사용하며 `GameThemeProvider`에서 카드·스페셜 포토·앨범 토큰·덱 그림을 적용한다. 테마 선택 창은 네 옵션의 두 열 배치와 모바일 대응을 제공한다. 인트로는 네이티브 모달로 게임판 조작을 차단한다.

| 기존 색 | 앨범 | 발매 |
| --- | --- | --- |
| 흰색 | 우리의 계절 (I Still Remember) | 2026-08-31 |
| 파랑 | LIKE INFINITE | 2025-03-06 |
| 초록 | INFINITE ONLY | 2016-09-19 |
| 빨강 | Destiny | 2013-07-16 |
| 검정 | Reality | 2015-07-13 |
| 황금 | Over the Top | 2011-07 |

최근 두 단체 발매작은 싱글을 포함한다. 남우현 솔로의 피처링 발매는 제외했다. 황금은 사용자 선택에 따라 ‘내꺼하자’가 수록된 Over the Top이며 객관적 인기 1위라는 뜻은 아니다.

호야를 제외한 개인 사진과 활동 사진을 사용한다. 우리의 계절에는 같은 달 무한대집회Ⅴ 공개 사진, Reality에는 성규·엘·성종 공개 사진을 사용한다. 7인 표지인 Destiny와 Over the Top은 인물이 없는 로고 영역만 표시한다. 카드에는 앨범·이름 태그를 표시하지 않는다. 원본 자산 출처는 `apps/web/src/assets/infinite/sources.json`에 기록했다. 출처 표기는 재사용 허가를 의미하지 않으며 자산의 권리는 원 권리자에게 있다.

배포 시 웹 Hosting 외에 Firestore rules와 Functions도 함께 반영해야 멀티에서 선택과 방 목록 표시가 동작한다.
