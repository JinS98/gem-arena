# 3D 예시 사용 안내

`/examples/3d`에서 직접 연다. 운영 헤더에는 3D 예시 메뉴를 표시하지 않는다. 멀티 게임판을 기준으로 디자인한 **혼자 체험하는 독립 시연**이다. 온라인 방·로그인·Firestore를 사용하지 않으며 기존 멀티 및 한 PC 대전의 진행 상태와 연결되지 않는다. 새로고침하면 초기화된다.

## 체험 방법

- 자유 플레이: 은행에서 서로 다른 색 최대 3개 또는 같은 색 2개를 고른다. 카드에는 실제 할인 비용과 구매 가능 여부가 표시된다.
- 카드 구매: 시장 카드에서 상세 비용·황금 대체 결제를 확인하고 구매한다. 결제 칩은 은행으로, 구매 카드는 내 영구 할인 칸으로 이동하고 시장에 새 카드가 공개된다.
- 카드 예약: 시장 카드나 단계별 뒷면 덱을 예약한다. 황금이 있으면 1개를 받고, 아래의 내 예약 카드에서 확인·구매한다.
- 보석 반환: 미리 준비된 초과 보석 2개를 선택해 반환한다.
- 귀족 방문: 조건을 갖춘 장면에서 강조된 귀족 한 명을 선택해 점수 획득을 확인한다.
- 상대 차례: ‘상대 행동 보기’가 같은 게임 엔진으로 상대의 구매·보석 획득 등을 한 행동씩 진행한다.
- 시간 초과 시연: 엔진의 TIMEOUT으로 보석 반환·귀족 선택 등 현재 단계에 맞는 자동 정리와 턴 전환을 확인한다.
- 기권 시연: 내 자산을 정리하고 상대 차례를 관전한다. 게임이 끝나면 결과를 확인할 수 있다.
- 모든 장면은 장면 초기화로 복구한다. 테마, 효과음, 움직임 줄이기를 바꿔서 비교할 수 있다. 효과음은 처음에는 꺼져 있다.

## 구현 범위

CSS perspective, 카드 기울기·종이 단면·덱 층, 펠트/목재 재질, 칩 스택과 Web Animations를 결합한 2.5D 예시다. WebGL 전체 3D 장면은 아니다. 시연 초기 배치는 행동을 바로 시험할 수 있게 준비한 중간 게임 상태이며, 실제 행동은 기존 game-engine의 비용·보유 한도·귀족·턴·종료 규칙을 따른다.

시연 화면은 자체 React 상태만 사용한다. 기존 Zustand 스토어·게임 서버와 연결되지 않으며 App의 독립 라우트에서 연다. 시연 스타일은 `.tabletop-example`에 한정한다. 이후 멀티 게임판에는 별도로 카드의 입체 표면·호버·구매 가능 태그와 보석 은행의 호버·선택 효과를 적용했다. 기존 카드 규격과 규칙은 유지한다.

## 주요 파일

- `apps/web/src/pages/TabletopDemoPage.tsx`: 멀티 형태 게임판, 장면 선택, 입력과 독립 게임 상태.
- `apps/web/src/data/tabletopDemo.ts`: 중간 게임 장면과 상대 행동 선택.
- `apps/web/src/components/TabletopScene.tsx`: 시각 소스 캡처, 입체 이동·착지·보충, 효과 설정.
- `apps/web/src/components/TabletopDialog.tsx`: 카드 결제와 예약/기권/결과 대화상자, 키보드 초점 관리.
- `apps/web/src/animations/tabletopEvents.ts`: 연속 확정 버전의 차이에서 연출 이벤트 생성. 같은 버전·건너뛴 버전·초기화는 재생하지 않는다.
- `apps/web/src/services/tabletopAudio.ts`: 사용자 입력 후 활성화되는 짧은 합성 효과음.
- `apps/web/src/tabletop.scss`: 독립 테이블 재질·반응형 화면·움직임 줄이기.

## 검증

`npm --prefix apps/web test`의 웹 테스트 8개 통과. 장면별 카드 중복·보석 보존, 실제 구매와 귀족 선택, 상대 행동의 완주, 이벤트 중복 방지 및 뒷면 예약 정보 분리를 검증했다.

Chrome에서 구매·시장 보충·애니메이션 정리, 시장/덱 예약·예약 카드 구매, 두 종류 보석 획득, 초과 반환, 귀족 방문, 상대 행동, 시간 초과, 소리/움직임 설정, 기권·관전·종료·재시작을 확인했다. 기존 한 PC 게임이 예시 행동의 영향을 받지 않는 것도 확인했다. 1440px 데스크톱과 390px 모바일에서 문서 전체의 가로 넘침이 없었다. 모바일 시장은 행별 가로 스크롤로 4장을 탐색한다.

실제 화면 캡처는 `docs/assets/3d-board-concepts/implemented-desktop.png`, `implemented-mobile.png`, `implemented-purchase.png`에 저장했다. 콘셉트 생성 이미지와 별개의 실제 구현 화면이다. 모바일 실기기와 Safari의 성능은 별도 검증이 필요하다.
