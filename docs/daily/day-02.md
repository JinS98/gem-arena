## 완료 기준
**기본판 규칙과 예외 케이스가 표로 정리된다**

## 작업 기록
- 구현 내용: [기본판 규칙](../game-rules.md)에 인원별 준비, 턴 순서, 보석·예약·구매·귀족·종료와 예외 R01~R16을 명세했다. 예시 보석 검사 함수가 3종 이상 남았을 때 1~2종만 받는 입력을 허용하던 문제를 수정하고 테스트를 보강했다. 구매 행동 타입은 결제 보석 전체를 전달하도록 변경하고 `PASS` 타입을 추가했다. [API 계약](../api-contract.md)에 턴 마무리 입력과 `PASS` 조건을 반영했다.
- 실행한 테스트/결과: `npm test` 보석 규칙 테스트 7개 통과. `npm run typecheck`에서 발견한 웹 앱의 Vite 환경 타입 선언 누락을 수정한 뒤 전체 타입 검사 통과.
- 이슈/의사결정: 실물 게임의 첫 플레이어 선정 대신 서버 무작위 선정, 합법 행동이 전혀 없을 때만 `PASS` 허용 및 전원 연속 `PASS` 시 점수로 종료하는 온라인 안전장치를 결정했다. 카드·귀족별 독자 데이터는 아직 없다.
- 다음 작업에 전달할 사항: 5일차에 독자 카드·귀족 데이터와 필요한 상태 필드를 만들고, 6~13일차에 R01~R16의 상태 전이·경계값·멱등성 테스트를 구현할 것. 서버 통합·권한 검증은 이후 일차에 실행한다.

## 검증 기록
- 규칙 출처: [Space Cowboys 기본판 규칙서](https://cdn.svc.asmodee.net/production-spacecowboys/uploads/2025/10/SCSPL01EN_SPLENDOR_RULES_LIGHT.pdf)와 요구사항 문서를 대조했다.
- 구현된 단위 테스트는 보석 획득 일부만 검증한다. 문서에 정의한 카드·귀족·최종 라운드·서버 예외의 실행 결과로 간주하지 않는다.
