## 오늘의 목표

- [ ] 입력·출력·예외 조건 정리
- [ ] **실시간 구독·낙관적 UI 최소화** 구현 또는 문서화
- [ ] 서버 확정 상태를 멀티 게임판의 상대 영역·귀족·3단계 시장·보석 은행·내 자원/예약 카드 영역에 연결한다. 다른 플레이어의 예약 카드는 수량만 표시한다.
- [ ] 관련 단위/통합/수동 테스트 작성 및 실행
- [ ] 실패 사례와 남은 작업 기록
- [ ] README 또는 설계 문서에 결정 사항 반영

## 관련 파일/폴더
`functions/src/, apps/web/src/services/, firestore.rules`

## 검증 시나리오
1. 정상 흐름이 기대한 결과를 반환하는지 확인한다.
2. 잘못된 입력 또는 권한이 거부되는지 확인한다.
3. 게임 상태를 바꾸는 작업이라면 중복 요청·경계값을 검증한다.
4. 서로 다른 브라우저에서 공개 정보는 같고, 내 예약 카드의 내용은 본인에게만 보인다.
