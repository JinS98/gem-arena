## 검증 시나리오
| 시나리오 | 기대 결과 | 1일차 검증 |
|---|---|---|
| 2~4명이 방 생성·참가·준비·시작·행동·결과까지 진행 | 사용자 흐름과 단계별 출력이 정의됨 | 요구사항·API 문서 대조 통과. 실행은 기능 구현 후. |
| 유효하지 않은 닉네임·코드, 만원/진행 중 방 참가, 미준비/비방장 시작 | 각 요청이 상태 변경 없이 거부됨 | 예외 조건 문서 대조 통과. 실행은 기능 구현 후. |
| 비멤버 또는 다른 플레이어가 비공개 상태 읽기 | 접근 거부 | 권한 요구사항·데이터 분리 설계 대조 통과. 실행은 보안 규칙 구현 후. |
| 동일 `actionId` 재전송, 다른 내용으로 재사용, 오래된 `expectedVersion` | 중복 적용 없음, 충돌은 명시적 거부 | API 계약 대조 통과. 실행은 서버 구현 후. |
| 새로고침/연결 끊김, 명시적 퇴장, UID 유실 | 같은 UID는 복귀, 명시적 퇴장은 기권, UID 유실은 복구 불가 | 운영 정책 문서 대조 통과. 실행은 재접속 구현 후. |

## 현재 구현 상태와 요구사항 확인 (2026-10-19)

| 영역 | MVP 요구사항 | 확인한 구현 상태 |
|---|---|---|
| 인증·방 | 익명 로그인, 닉네임, 비공개 방 생성·참가·준비·시작 | Firebase 초기화 함수만 있음. 로비는 미리보기이며 인증 및 방 API는 없음. |
| 게임 진행 | 2~4인 턴제, 보석·카드·귀족·승리 조건 | 엔진의 상태·액션 타입과 보석 획득 가능 여부 검사 일부만 있음. 카드·귀족·턴 전이·종료 판정은 없음. |
| 동기화·보안 | 실시간 상태 동기화, 중복 요청 방지, 재접속, 비공개 정보 보호 | Callable Functions는 비어 있고 Firestore 접근은 모두 거부됨. 데이터 분리와 멱등성은 설계 문서에만 있음. |
| 화면 | 반응형 게임판, 결과 화면 | 홈·로비·게임판 미리보기 경로와 카드 선택 UI 상태만 있음. 실제 게임판과 결과 화면은 없음. |

근거: [요구사항](../requirements.md), [기본판 규칙](../game-rules.md), [아키텍처](../architecture.md), [API 계약](../api-contract.md), [데이터 모델](../data-model.md), `apps/web/src/`, `packages/game-engine/src/`, `functions/src/index.ts`, `firestore.rules`.

확인된 MVP 사용자 흐름은 **방 생성 → 초대 → 2~4명 준비 → 게임 시작 → 턴별 행동 → 마지막 라운드 → 결과**다. 성공 기준은 별도 브라우저 2~4개에서 게임을 끝까지 진행하고 비공개 정보가 노출되지 않는 것이다. 현재 구현으로는 이 흐름을 검증할 수 없다.

범위 밖으로 명시된 기능은 AI, 공개 매칭, 랭킹, 친구 목록, 채팅, 관전자다. 진행 중 이탈, 무응답, 익명 UID 유실 정책은 [요구사항](../requirements.md)과 [아키텍처](../architecture.md)에 결정했다. 이 표는 구현 현황이며, 확정된 목표 기능이 이미 구현되었다는 뜻은 아니다.

## 작업 기록
- 구현 내용: 요구사항·구현 현황을 대조하고, [MVP 범위·사용자 흐름·운영 정책](../requirements.md), [API 입력·출력·예외](../api-contract.md), [아키텍처 결정](../architecture.md), [데이터 모델 메모](../data-model.md)를 문서화함. 기능 구현 변경은 없음.
- 실행한 테스트/결과: 위 5개 문서 검증 시나리오를 수동으로 대조해 일치 확인. 기존 `npm test`에서 보석 규칙 테스트 4개 통과. 미구현 기능의 통합·보안·브라우저 테스트는 실행 불가.
- 이슈/의사결정: 명시적 진행 중 퇴장은 기권, 단순 연결 끊김은 자리 유지, 턴 타이머 없음, UID 유실 시 자리 복구 불가로 결정. 무응답으로 게임이 멈출 수 있는 것은 알려진 MVP 한계.
- 다음 작업에 전달할 사항: 2일차에 규칙별 입력·경계값·예외를 확정하고, 이후 구현 일차에 위 시나리오를 실제 통합·보안·브라우저 테스트로 실행할 것.
