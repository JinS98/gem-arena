## 입력·출력·예외 조건

- 입력: `/game/demo` 경로에서만 3인 고정 샘플 게임판을 표시한다. 샘플은 공개 카드·귀족 카탈로그와 화면 전용 플레이어·은행 수량만 사용한다.
- 출력: 현재 차례, 점수·영구 할인·예약 수, 귀족 요구량, 카드 비용과 보너스, 은행 수량을 표시한다. 모바일에서는 내용이 잘리지 않도록 목록을 가로 스크롤한다.
- 예외: 실제 방 ID는 아직 연결되지 않았다. `/game/demo` 이외 주소에는 미리보기 링크를 보여준다. 화면에서 게임 상태를 변경하는 입력은 제공하지 않는다.

## 작업 기록
- 구현 내용: 페이지·플레이어 패널·귀족·카드·은행 컴포넌트를 추가하고 반응형 스타일을 적용했다. 홈과 로비에서 게임판 미리보기로 이동할 수 있다.
- 실행한 테스트/결과: `npm run typecheck`, `npm run build` 통과. 로컬 Vite 서버에서 1440px 데스크톱과 500px 좁은 화면을 렌더링해 배치를 확인했다.
- 이슈/의사결정: 서버 API와 공개 상태 구독 전이므로 게임판은 고정 샘플을 사용한다. 비공개 덱과 예약 카드 ID는 미리보기 데이터에 넣지 않았다. 조작 기능을 암시하지 않도록 카드는 읽기 전용으로 표시한다.
- 다음 작업에 전달할 사항: 15일차 보석 획득·반환, 16일차 카드 구매·예약 입력을 이 레이아웃에 연결한다. 17일차에는 턴·귀족 선택·결과를 표시하고, 이후 서버 확정 공개 상태와 개인 상태로 샘플을 교체한다.
