# 12일차 — 15점 최종 라운드·동점 판정

**단계:** 게임 엔진  
**예상 시간:** 3~4시간  
**상태:** 완료

## 오늘의 목표
귀족 방문까지 끝난 턴의 15점 도달을 판정하고, 모든 플레이어가 같은 수의 턴을 마친 뒤 승자를 결정한다.

## 검증 시나리오
| 입력·조건 | 기대 출력 | 실행 결과 |
|---|---|---|
| 14점 이하로 라운드 마지막 턴 종료 | 계속 진행, 다음 턴 귀족 판정 초기화 | 통과 |
| 무작위 첫 플레이어가 15점 도달 | 해당 라운드의 나머지 모든 턴 후 종료 | 통과 |
| 중간 순서가 15점 도달 | 남은 순서의 턴 후 종료 | 통과 |
| 2~4인에서 마지막 순서가 15점 도달 | 즉시 종료 | 통과 |
| 최고 점수 동점, 구매 카드 수 차이·동일 | 적은 카드 보유자 승리·공동 승리 | 통과 |
| 귀족 판정 전·잘못된 단계/행위자·종료 뒤 재요청·잘못된 상태 | 거부, 원본 상태 유지 | 통과 |

## 입력·출력·예외 조건

- 입력: `completeTurn(state, playerId)`는 현재 플레이어가 `playing` 단계에서 귀족 판정을 마친 상태를 받는다. `determineWinnerIds(state)`는 점수와 구매 카드 수를 비교한다.
- 출력: 15점 이상을 처음 확인하면 `finalRoundTriggeredBy`를 기록한다. 초기 `firstPlayerIndex`를 기준으로 라운드 마지막 턴까지 진행하고 `phase: 'finished'`, `winnerIds`를 반환한다. 다음 턴에는 `turnNobleResolved: false`를 설정한다. 원본 객체와 `version`은 변경하지 않는다.
- 예외: 잘못된 단계·행위자·턴 순서·점수·최종 라운드 기록은 `RangeError`로 거부한다. 종료 후 다시 호출할 수 없다.

## 작업 기록
- 구현 내용: 무작위 첫 플레이어의 좌석을 `firstPlayerIndex`로 보존하고, 턴 완료·최종 라운드·점수/구매 카드 수 순의 승자 판정 순수 함수를 추가했다.
- 실행한 테스트/결과: `npm test` 62개 통과(12일차 9개 포함), `npm run typecheck` 및 `npm run build` 통과.
- 이슈/의사결정: 참가 순서의 마지막 좌석이 항상 라운드 마지막은 아니다. 첫 플레이어 직전 좌석을 경계로 계산한다. 기권 상태가 아직 없으므로 이 함수는 현재 `playerOrder`의 모든 참가자를 대상으로 한다.
- 다음 작업에 전달할 사항: 13일차 reducer에서 기본 행동·초과 보석 반환·귀족 방문/선택 뒤 `completeTurn`을 호출하고, 성공한 상태 전이마다 `version`을 갱신한다. 26일차 기권 처리에서는 활성 플레이어만 턴·승패에 포함하고 최종 라운드 경계를 다시 계산해야 한다.
