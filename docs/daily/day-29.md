## 검증 시나리오
1. 정상 흐름이 기대한 결과를 반환하는지 확인한다.
2. 잘못된 입력 또는 권한이 거부되는지 확인한다.
3. 게임 상태를 바꾸는 작업이라면 중복 요청·경계값을 검증한다.
4. PC 화면에서 카드 비용·귀족 조건·상대 공개 상태·내 보유량과 예약 카드에 스크롤 없이 접근하고, 모바일에서도 주요 행동을 완료한다.
5. 획득 연출과 알림은 실제 서버 확정 결과를 반영하며, 움직임 줄이기 설정과 키보드 조작에서도 결과가 읽힌다.
