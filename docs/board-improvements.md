# 추가된 내용 — 게임판 화면·상호작용 개선

이 기록은 일차별 작업표와 별도로 적용한 게임판 개선을 정리한다. 주 대상은 멀티 게임 `/game/:roomId`이며, 카드 할인 비용 표시는 로컬 게임 `/game/demo`에도 적용했다.

## 화면 배치와 정보 표시

- 멀티 게임에서는 공통 사이트 헤더를 숨기고 게임판이 브라우저 너비를 사용한다. 넓은 화면의 카드 시장은 중앙에 모아 간격을 줄이고, 귀족·상대 현황은 왼쪽, 은행·내 행동·내 현황은 오른쪽에 배치했다. 화면 높이가 부족하면 양쪽 정보 영역을 내부 스크롤로 볼 수 있다.
- 단계별 덱을 개발 카드와 같은 비율의 뒷면 카드로 표시하고 레벨마다 색을 달리했다. 귀족 3장은 한 줄의 정사각형 카드로, 4장 이상이거나 높이가 부족한 경우에는 화면 조건에 맞게 배열 또는 간결한 목록으로 표시한다.
- 상대 현황과 내 현황에 보유 보석·구매 카드 할인을 구분해 표시했다. 내 현황은 간단 보기와 자세히 보기를 전환하며, 예약 카드의 점수·보너스·비용 요소는 작은 카드에서도 읽을 수 있게 조정했다.
- 보석이 10개를 넘을 때의 반환 목록은 아이콘, 보유량, 반환 수량 조절 버튼을 각각 고정된 영역에 배치했다. 보석 아이콘이 행 너비만큼 늘어나던 문제를 해결했다.

## 구매·보석·카드 연출

- 카드 구매 버튼을 누르면 모달에 처리 상태가 즉시 나타난다. 서버가 구매를 확정하면 모달이 줄어들고, 구매한 시장 슬롯을 잠시 비운 뒤 해당 레벨의 뒷면 덱 카드가 빈자리로 이동하며 새 카드가 공개된다. 실패 메시지는 모달 안에도 표시한다.
- 보석 받기와 초과 보석 반환 버튼에는 요청 중 표시와 안내 문구를 제공한다. 보석 받기가 확정되면 은행에서 내 보유 칸으로, 반환이 확정되면 내 보유 칸에서 은행으로 보석이 이동한다. 반환 수량만큼 이동 효과를 만들고, 도착에 맞춰 내 보유량을 줄이며 은행 아이콘을 강조한다.
- 시장 카드와 내 예약 카드에 마우스를 올리거나 키보드 초점을 맞추면, 구매 카드 보너스를 반영한 실제 색상별 비용으로 칩이 전환된다. 할인된 색상은 강조하고 모든 비용이 0이면 `무료`로 표시한다. 계산에는 게임 엔진의 `remainingCardCost`를 사용한다.
- 움직임 줄이기 설정에서는 이동 및 전환 효과를 건너뛰고 결과를 표시한다.

## 멀티 게임 시작·기권·종료

- 방장이 모두 준비된 방에서 게임 시작을 누르면 방 상태를 구독하는 모든 참가자가 자동으로 멀티 게임판으로 이동한다. 게임 문서가 만들어지는 동안에는 준비 안내를 표시한다.
- 기권 버튼은 관전 또는 로비 퇴장을 선택하는 모달을 연다. 활성 참가자가 3명 이상이면 기권 후 관전을 계속할 수 있다.
- 활성 참가자가 두 명일 때 한 명이 기권하면 게임을 즉시 종료한다. 기권자는 로비로 이동하고 승리한 참가자에게 승리 모달과 로비 이동 버튼을 표시한다.
- 에뮬레이터 연습용 초기 보석·시장 조정은 제거했다. 모든 멀티 게임은 인원별 정상 은행 수량과 참가자 보석 0개로 시작한다.

- `npm test`: 엔진 84개와 웹 1개 테스트 통과. `npm run build`: 엔진·웹·Functions 빌드 통과.
